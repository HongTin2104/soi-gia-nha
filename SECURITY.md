# Security policy

soi-gia-nha runs on your own machine. The app does not store the listings you paste and sends
them nowhere; its only network access is downloading the model and data archives from this
repository's [releases](https://github.com/HongTin2104/soi-gia-nha/releases) on first start.

If you find a security problem (for example in how those archives are downloaded and unpacked, or
input that crashes or hangs the app), please do not open a public issue. Report it privately
through [GitHub's private vulnerability reporting](https://github.com/HongTin2104/soi-gia-nha/security/advisories/new)
or by email to hongtin2104@gmail.com. You should get a reply within a week.

A price estimate that looks wrong is not a security issue; please use the
[wrong estimate](https://github.com/HongTin2104/soi-gia-nha/issues/new?template=wrong-estimate.yml)
form.

Only the latest release is supported.
